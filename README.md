# 상사 패기 🔥

부장님에게 사직서와 온갖 무기를 날리는 직장인 스트레스 해소 게임. 의존성 없는 단일 `index.html` — 웹/모바일 겸용.

## 게임

### 😤 사직서(무기) 던지기
- 사직서를 드래그해 던지거나, **부장님을 터치하면 장착 무기가 얼굴로 자동 발사**됩니다
- 던진 속도에 따라 톡 → 퍽! → **크리티컬!!** 3단계 연출 (히트스톱, 스쿼시/스트레치, 충격파, 광선, 화면 진동, 합성 타격음)
- 타격으로 **퇴근 러시**를 충전하면 8초간 데미지와 연타 속도, 임팩트가 함께 폭주합니다
- 타격 EXP로 런 레벨이 오르며 레벨마다 데미지 +10%와 사이다 보상을 받습니다
- 각 보스는 25초 제한입니다. 시간 안에 못 잡으면 자동 환생해 현재 진행도에 비례한 영구 공격력을 받고 같은 회사의 사원부터 재도전합니다
- 상사를 K.O.할 때마다 뱀서류 방식의 **증강 3택**이 등장합니다. 데미지·크리티컬·러시·보상 강화가 이번 이직 런 동안 누적됩니다
- 콤보 시스템 + 상사 멘탈 게이지. 5개 회사의 13개 직급, 총 65명의 상사를 돌파하면 엔딩이 열립니다
- 마지막 대기업 회장을 격파하면 런 통계와 영구 +50% 훈장을 받고, 무기·경력을 유지한 2회차를 시작할 수 있습니다
- 타격/KO마다 🥤 사이다를 벌어 **사내 매점**에서 무기 구매 — 무기를 사면 투사체가 그 무기로 바뀝니다
  - 모든 무기는 이모지 대신 동일한 2.5D 아트 스타일의 커스텀 PNG 에셋을 사용합니다
  - 결재 만년필, 기계식 키보드, 야근 몽둥이, 임원용 체어샷, 고무줄 결재총, 임원 서류가방
  - 신규 전설 무기: **법인카드 부메랑**, **인사팀 해고 도장**

### 💥 회사 폭파 (추후 별도 개발 예정 — 현재 비활성화)
- 코드는 남아 있으나 탭이 숨겨져 있습니다. 전국 실시간 집계는 [counterapi.dev](https://counterapi.dev) 공용 카운터 기반.

## 실행

정적 파일이라 아무 웹서버로 열면 됩니다:

```sh
npx serve .
```

사운드는 전부 Web Audio API 합성이라 오디오 파일이 없고, 캐릭터는 인라인 SVG입니다.

게임 로직의 순수 상태 전이는 Node 내장 테스트로 검증합니다.

```sh
node --test tests/*.test.mjs
```

## React Native 앱

`mobile/`은 Expo SDK 55 + `react-native-webview` 기반의 네이티브 셸입니다. 기본값으로 운영 웹 게임(`https://sangsahit.kro.kr/`)을 불러옵니다.

```sh
cd mobile
npm install
npx expo start
```

로컬 웹 서버를 WebView에서 확인하려면 기기에서 접근 가능한 주소를 지정합니다. 실제 기기에서는 `localhost` 대신 개발 PC의 LAN IP를 사용해야 합니다.

```sh
EXPO_PUBLIC_GAME_URL=http://192.168.0.10:4173 npx expo start
```

외부 링크는 시스템 브라우저로 열리고, WebView 내부 이동은 게임과 같은 출처로 제한됩니다.

## 이벤트 트래킹

- **페이지뷰**: Vercel Web Analytics (무료). Vercel 대시보드 → 프로젝트 → **Analytics** 탭에서 Enable 한 번만 누르면 자동 집계됩니다.
- **커스텀 이벤트**: [Mixpanel](https://mixpanel.com) (무료 플랜: 월 100만 이벤트). Vercel 무료 플랜은 커스텀 이벤트를 지원하지 않아 Mixpanel을 씁니다.
  1. Mixpanel 프로젝트를 만들고 **Project Token**을 복사
  2. `index.html`의 `const MIXPANEL_TOKEN = ''` 에 토큰을 붙여넣고 재배포
  - 수집 이벤트: `app_open`, `boss_ko`(세대·무기), `weapon_purchased`(무기·가격), `weapon_equipped`, `shop_opened`
  - 토큰이 비어 있으면 트래킹은 조용히 꺼지고 게임은 그대로 동작합니다.
